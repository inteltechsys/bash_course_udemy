# Créer un nouveau script

1. Créer le script à la racine : shebang #!/bin/bash, variables entre guillemets, commentaires en français.
2. Créer en même temps son test : test_<nom du script>.
3. Rendre les deux exécutables avec chmod +x.
4. Passer shellcheck sur les deux fichiers.
5. Lancer le test et me montrer la sortie.
